# Линейная регрессия — лабораторная работа 2

Jupyter-ноутбук с решением лабораторной работы по линейной регрессии.

## Содержание

1. **Метод наименьших квадратов** — аналитическое решение задачи МНК.
2. **Линейная регрессия** — построение модели на данных о квартирах в Москве, усложнение модели.
3. **Регуляризация** — L1/L2-регуляризация и её влияние на модель.
4. **Онлайн-обучение линейной регрессии** — обновление модели по мере поступления данных.
5. **Дополнительно: QR-разложение** — решение задачи МНК через QR-разложение.

## Как использовались библиотеки

Модели в работе написаны вручную на NumPy. Готовые реализации регрессии
из scikit-learn не используются: из него взято только разбиение выборки.

### 🔢 NumPy: вся линейная алгебра

| Задача | Что использовано |
|---|---|
| Загрузка `train.txt` / `test.txt` | `numpy.loadtxt` |
| Матрица признаков (столбец единиц, степени `x`) | `np.ones`, `np.concatenate`, `np.c_`, `np.vstack([x ** p ...]).T` |
| МНК и полиномиальная аппроксимация | `np.linalg.lstsq` |
| Аналитическое решение для квартир | нормальное уравнение `np.linalg.inv(X.T @ X) @ X.T @ y` |
| L2-регуляризация (гребневая регрессия) | `np.linalg.inv(X.T @ X + λ·E)`, где `E = np.eye(...)`; перебор `λ` по сетке `np.logspace(-4, 4, 50)` |
| Онлайн-обучение | накопление `XᵀX` через `np.outer` и `Xᵀy` по одной точке, пересчёт весов через `np.linalg.solve` |
| Метрики | MSE вручную: `np.mean((y - y_pred) ** 2)` |
| Синтетические данные | `np.random.uniform`, `np.random.randn` |
| Новые признаки | `np.log` для `log(totsp)` |

### 🐼 pandas: работа с табличными данными

- Чтение датасета о квартирах в Москве: `pd.read_csv('flats_moscow_mod.txt', sep='\t')`.
- Выбор признаков (`totsp`, `livesp`, `kitsp`, `dist`, `metrdist`) и целевой переменной `price`.
- Новые признаки прямо в датафрейме: `totsp²`, `dist²`, `log(totsp)`, `totsp · metrdist`.

### 🤖 scikit-learn: разбиение выборки

- `train_test_split(..., test_size=0.3, random_state=42)` делит данные о квартирах на обучение и тест.
- Тот же `train_test_split` выделяет валидационную часть, по которой подбирается коэффициент регуляризации `λ`.

### 📈 matplotlib: визуализация

- Точки обучающей и тестовой выборок (`plt.scatter`) и подобранные кривые (`plt.plot`) на сетке `np.linspace`.
- Сравнение многочленов степеней `k = 1..6` на одном графике.
- Многочлен 6-й степени с регуляризацией и без неё.
- Онлайн-обучение: график перерисовывается каждые 5 точек через `IPython.display.clear_output`, видно, как предсказание приближается к истинной функции.
