# Линейная регрессия — лабораторная работа 2

Jupyter-ноутбук с решением лабораторной работы по линейной регрессии.

## Содержание

1. **Метод наименьших квадратов** — аналитическое решение задачи МНК.
2. **Линейная регрессия** — построение модели на данных о квартирах в Москве, усложнение модели.
3. **Регуляризация** — L1/L2-регуляризация и её влияние на модель.
4. **Онлайн-обучение линейной регрессии** — обновление модели по мере поступления данных.
5. **Дополнительно: QR-разложение** — решение задачи МНК через QR-разложение.

## Запуск

```bash
pip install -r requirements.txt
jupyter notebook homework_practice_02_linregr_Novoselova.ipynb
```

## Данные

Ноутбук изначально запускался в Google Colab и использует файлы
`flats_moscow_mod.txt`, `train.txt` и `test.txt` из папки `/content/`.
Для локального запуска положите эти файлы рядом с ноутбуком и замените пути
`/content/...` на имена файлов.

## Стек

Python, NumPy, pandas, matplotlib, scikit-learn, SymPy
